# 胶体量子点发光二极管发光机理研究 · 论文可视化网站

一个纯静态（HTML + CSS + 原生 JavaScript，零依赖）的中文可视化网站，把学位论文
《胶体量子点发光二极管发光机理研究》（中国科学技术大学，凝聚态物理，2024 年 4 月 2 日，共 143 页 / 6 章）
的摘要、机理、数据与图表整理成可交互的长页面。

## 打开方式

直接双击 `index.html`，或拖进任意浏览器即可（无需服务器、无需联网）。
页面支持深色主题、滚动进度、分区导航、滚动揭示动画与图片灯箱。

## 数据与图片说明

- 所有数值、图注、结论均取自论文原文，未作推断性补充；图号与图题引用自论文图注。
- 图片直接取自 PDF 中的原始插图（PyMuPDF 抽取，仅保留尺寸较大的图），版权归原作者与培养单位，
  此处仅用于学习交流。
- 图表中的拟合线（如 T95-初始亮度）依据论文给出的加速因子（n≈1.71–1.87）绘制，实心点为实测数据，
  空心点为论文按加速因子外推的结果。

## 可访问性与健壮性

- `prefers-reduced-motion`：关闭全部动画/过渡，且直接显示所有内容。
- `<noscript>`：禁用 JavaScript 时内容依然可见（滚动揭示类元素强制显示）。
- 即使 `IntersectionObserver` / `requestAnimationFrame` 不可用，也有定时兜底，
  避免出现"空白页面"；图表会直接绘制终态。
